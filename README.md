# Project Management Form using JsonPowerDB

## Description
This project is a Project Management Form developed using HTML, CSS, JavaScript, Bootstrap, and JsonPowerDB. The application allows users to store, update, and manage project records using JsonPowerDB as the backend database.

## Features
- Add new project records
- Update existing project records
- Reset form data
- Primary key validation
- Dynamic form field enable/disable
- Database integration using JsonPowerDB

## Input Fields
- Project ID
- Project Name
- Assigned To
- Assignment Date
- Deadline

## Primary Key
- Project ID

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- JsonPowerDB

## Benefits of using JsonPowerDB
- Simple to use
- Lightweight
- Fast and efficient
- REST API based database
- Serverless support
- Easy integration with web applications
